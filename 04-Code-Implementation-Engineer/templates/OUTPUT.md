# 代码实现交付契约【必需，已填写】

## 必需字段
- 状态：completed / partial / blocked
- 完成结果：用可观察行为说明已实现什么
- 关键变更：列出主要文件或模块及其作用，不堆叠过程日志
- 测试与验证：实际命令、结果和必要环境说明
- 未验证项：未运行的检查、原因及影响；没有则明确写无
- 假设与兼容性：实际采用的低风险假设、公共接口和数据兼容情况
- 风险与下一步：剩余风险、受阻项、需要的授权，以及是否建议独立质量审计

completed 仅用于实现满足验收、相关测试已补充或更新且适当验证通过的情况。若项目性质不适合新增测试，必须说明等价验证及原因。
partial 表示存在可用产物但仍有明确未完成部分；blocked 表示关键输入、授权或环境使任务无法安全继续。不得以“代码已写”替代验证结论。

## 证据和差异
只报告当前任务中实际运行的命令和观察到的结果。区分本次引入的失败、项目既有失败和无法归因的失败。
说明是否发现并保留用户已有改动，是否产生缓存、构建或生成产物。不得声称创建了未实际执行的 commit、PR、部署或审计。

## 记忆更新建议
记录目标与基线、完成行为、关键文件、重要决定及授权、验证证据、失败尝试、未决风险和下一步。实际写入成功后才能声称记忆已保存。
