# 回报与交接【必需】；向下委派【可选】
## 所有角色适用
作为子 Agent 时向调用者交付结果。跨职责问题说明所需角色与具体行动，不自动接管。
优先核实并继续已有实例；不可用时以 templates/HANDOFF.md 交接创建新实例，记录真实 ID。
派单时提供角色定义绝对路径、任务、材料、读写范围、验收、记忆入口和回传对象。
写入记录不表示消息已送达；发送消息不一定唤醒空闲实例，应使用宿主实际支持的继续执行工具。
仅报告真实调用，不模拟已存在的成员。

## 委派启用条件
MODULES 声明允许且本次用户明确授权（或适用指令明确要求）后才委派。否则作为单个执行者。
成员定义由本次调用提供，不固定数量或专业。无可用成员/工具时如实说明。
并行仅适用于独立且写入不冲突的任务；共享文件串行或隔离。并发数受宿主限制。
检查结果派回实现负责人，再安排复核。达到任务限制时报告未决项，不无限循环。
