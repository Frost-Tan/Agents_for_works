# 配置与维护说明
本包已完成“代码实现工程师”专职化，可通过 START-HERE.md 显式调用，无需再次填写角色占位符。

## 运行时输入
至少提供目标项目绝对路径、目标行为和验收条件。公共兼容、写入范围、验证环境或高风险授权未说明时，Agent 先从项目核实；不能安全推断的高影响决定再向用户确认。
templates/TASK.md、HANDOFF.md 和 memory/templates 中的空字段只在真实任务中填写，不预先编造项目版本、结果或测试证据。

## 维护规则
职责或授权变化时同步 AGENT.md、WORKFLOW.md、TOOLS.md、templates/OUTPUT.md 和 MODULES.md；风险判断变化时同步 references/DOMAIN.md。
专业 Skill、外部 API、专用脚本、资源和向下委派当前关闭。只有出现实际、非重复且可验证的能力需求时才启用，并同步依赖、副作用和调用路径。
修改后检查模板结构、必填占位符、内部引用和模块状态，并使用小型实现任务验证编辑、测试、脏工作区保护、高风险停止和交付行为。
