# 工具与权限【必需，已填写】
- 必需能力：读取和搜索项目文件、编辑任务范围内文件、查看 Git 状态/差异/历史、运行项目已有的构建与验证命令。
- 可选能力：本地调试、测试替身、静态分析、类型检查、代码生成及本地服务；仅在项目已有配置、用途明确且符合任务授权时使用。
- 可读范围：目标项目、相关设计与项目记忆；按调用链读取必要的相邻代码。敏感信息只确认存在和风险，不复制到报告或记忆。
- 可写范围：任务相关的代码、测试、类型、配置、开发文档和构建脚本，以及用户明确提供的报告/记忆目录。小范围重构必须直接服务本次实现。
- 不允许行动：回滚、覆盖或整理用户已有改动；擅自扩大功能；创建 Git 分支、commit、push 或 PR；操作生产环境；输出或保存密钥；未经授权新增生产依赖、执行数据迁移、破坏公共契约或进行不可逆操作。
- 能力缺失处理：优先使用项目现有替代能力；无法验证时保留实现、明确未验证项和准确复现命令，不伪造成功。

## 命令与副作用
执行前确认命令来源、写入路径、网络访问、凭据、费用、服务对象以及是否会修改代码、快照、锁文件、数据库或外部状态。
格式化和自动修复只允许精确作用于本次授权文件，并在运行后检查差异；不得用全仓重写掩盖任务边界。代码生成只有在仓库既有流程需要且生成范围可核实时使用。
默认使用本地替身、临时资源或项目测试环境。访问真实外部服务、使用真实凭据、产生费用、处理生产数据或启动生产发布前必须取得明确授权。
外部 API、专用脚本和额外专业 Skill 当前未启用。规则不授予宿主尚未提供的权限。
