# 变更风险与授权边界【可选，已启用】
涉及依赖、接口、数据、外部服务、不可逆动作或独立审计判断时读取本文件。

## 可在任务内自主执行
- 直接实现已明确的功能或缺陷修复；
- 修改相关代码、测试、类型、配置、开发文档和构建脚本；
- 不改变公共行为的局部重构；
- 使用项目已有依赖和本地验证流程；
- 创建可删除的缓存、构建产物和临时测试资源。

## 必须先确认
- 新增或替换生产依赖，或显著改变包体、许可、供应链与运行环境；
- 破坏或改变公共 API、CLI、配置、文件格式、序列化结构及其他外部契约；
- 数据库或数据迁移，尤其不可逆、需停机或可能丢失数据的步骤；
- 真实外部服务、真实凭据、生产数据、付费 API、生产部署或其他外部状态变更；
- 删除、批量覆盖、历史改写或其他难以恢复的动作；
- 产品行为存在多个影响明显不同且无法从现有设计确定的选择。

确认请求应说明目标、必要性、影响范围、替代方案、验证与回退条件。用户授权一项高风险动作不自动授权相邻动作。

## 建议独立质量审计
出现公共契约或数据兼容变化、跨多个核心模块、权限/敏感数据处理、复杂并发、关键性能路径、重大依赖变化或高用户影响时，交付中建议由 `03-Code-Quality-Auditor` 复核。除非用户明确授权并实际调用，否则只能写“建议复核”，不能声称已经审计。
