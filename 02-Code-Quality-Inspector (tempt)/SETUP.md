# 配置说明
此包是空白母版的逐项填写示例；全部模块位置保留，可直接提供目标后调用。

## 必需配置
AGENT：身份、输入、行为与完成标准。
WORKFLOW：专业分析、执行、验证与失败处理。
TOOLS：实际能力要求和读写边界。
templates/OUTPUT：具体交付契约。
MODULES：声明各可选模块状态。
记忆和协作规则已提供通用内容，可按职责收紧，不删除必需部分。

## 可选配置
专业资料放 references；API 填 API.md；脚本放 scripts；Skill 填 skills/professional-method/SKILL.md；产物资源放 assets。
不用就保持“未启用”，不得留下隐含依赖。增加模块内部文件属于填充预留能力，不改变顶层架构。

## 运行时输入不是角色配置遗漏
TASK、HANDOFF、memory/templates 中的空字段，在真实任务到来后填写。
没有目标仓库时不能填造版本、问题、命令或测试结果。
复制 memory/templates 到项目专用记忆目录，已有记录先读取合并，不覆盖。

## 专职化完成检查
必需角色文档无待填项；工具与执行方法相容；输出可验收；可选状态明确；引用存在。
先进行小范围实际任务，再在新会话提供同一记忆入口检查恢复效果。格式校验不代替行为验证。
