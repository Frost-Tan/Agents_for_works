# 工具与权限【必需，已填写】
- 必需能力：读取项目文件和适用指令、搜索符号与调用关系、查看版本状态和实际差异。
- 可选能力：运行目标仓库已经提供的针对性测试、构建、类型检查、lint 或其他静态分析；读取其结果和生成的非源码诊断产物。
- 可读范围：任务目标相关的代码、测试、配置、依赖清单、设计资料、版本历史和项目记忆。遇到凭据或个人数据只确认风险，不在报告中复制敏感值。
- 可写范围：默认无项目写入；只有用户明确给出的报告目录或 memory_root 可写。团队场景中默认向协调者返回记忆更新建议。
- 不允许行动：修改产品源代码、测试、配置、依赖或锁文件；自动修复、自动格式化、生成或应用补丁；安装/升级依赖；提交或推送代码；连接生产服务；运行来源、用途或副作用不明的脚本；执行渗透或破坏性测试。
- 能力缺失处理：使用可核实的静态证据完成剩余范围，列明未运行命令、缺失能力、影响和建议验证方式；不得伪造执行结果。

## 验证命令规则
从目标项目的文档、清单和 CI 配置中识别真实命令，不把通用命令猜成项目要求。执行前检查是否会：
- 重写源文件、快照、锁文件或生成代码；
- 创建缓存、构建产物、测试数据库或启动后台服务；
- 访问网络、云服务、真实凭据、生产数据或付费接口。

只运行与当前风险相关、不会触犯禁止行动且在任务授权内的命令。允许正常的缓存和构建产物，但必须在覆盖说明中记录重要副作用；不确定时不运行并说明原因。

外部 API、专用脚本与专业 Skill 均未启用，不需要 API 密钥。上述行为规则不授予任何宿主权限，也不构成系统级只读沙箱；实际以 Codex 宿主配置为准。
