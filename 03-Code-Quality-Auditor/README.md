# 代码质量审计员
这是由完整 Agent 母版专职化得到的跨语言代码质量审计角色。它在明确范围内检查正确性、可靠性、可维护性、测试质量、性能、基础安全、依赖与配置，以及接口和数据兼容性；输出可复核的问题报告和门禁建议，但不修改产品代码。

## 使用方式
从其他项目调用时，明确要求 Codex 读取本目录 AGENT.md，并提供目标项目绝对路径、审查目标和基线。可直接复制 START-HERE.md 中的调用格式。

最小任务输入包括：
- 项目绝对路径与审查目标；
- 审查类型或目标差异/模块；
- 允许运行的验证范围；
- 如需落盘，明确报告目录或 memory_root。

未给报告目录时，Agent 默认在回复中交付。未指定详细范围时，它会从项目中建立有界范围并声明覆盖限制，不会声称完成无限范围的全仓证明。

## 角色边界
- 可以读取代码与差异，并在安全边界内运行仓库已有测试、构建和静态分析。
- 不修改代码、测试、配置、依赖或锁文件，不运行自动修复，不安装依赖，不连接生产。
- 只给修复原则和复核条件，不生成补丁草案。
- 基础安全问题属于质量检查范围；深度安全、渗透、合规和供应链取证需移交专职角色。
- pass_within_scope 仅表示已声明范围内没有确认的阻断问题，不代表项目绝对无缺陷。

## 包结构
| 文件/目录 | 作用 |
| --- | --- |
| AGENTS.md、AGENT.md | 加载入口、角色身份和职责边界 |
| MODULES.md | 必需与可选模块的启用状态 |
| WORKFLOW.md、TOOLS.md | 审计方法、验证权限和停止条件 |
| references/DOMAIN.md | 严重程度、置信度、证据和安全边界 |
| templates/TASK.md、OUTPUT.md | 任务输入与报告契约 |
| templates/HANDOFF.md、collaboration/ | 真实交接与协作规则 |
| memory/ | 外置项目记忆的规则和空模板 |
| skills/、scripts/、assets/、references/API.md | 当前关闭的预留模块 |

角色包只保存规则和空白运行时表格。实际项目报告和记忆应写到任务明确授权的外部目录。文件约束 Agent 行为，但不会创建系统级权限沙箱，也不会自动注册为 Codex 常驻角色。
