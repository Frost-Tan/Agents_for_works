# 配置与维护说明
本角色已配置完成。实际调用时填写 templates/TASK.md 的项目、主场景、Godot版本、设计基线、审批人和验收条件，不把运行时信息写回角色包。

## 默认配置
- Godot 4.x；准确小版本从 project.godot 核实。
- 2D及卡牌/策略优先，GDScript项目惯例优先。
- 正式设计默认进行3–5个相关竞品或公开资料研究。
- 设计文档与设计侧表格可写；产品代码、场景、资源和运行时配置只读。
- references/DOMAIN.md 已启用；额外 Skill、固定API、脚本、资产和向下委派关闭。

## 未来调整
若要支持Godot 3.x、C#优先、完整3D设计或允许修改运行时数据，必须同步修改 AGENT.md、WORKFLOW.md、TOOLS.md、DOMAIN、TASK、OUTPUT和MODULES，不能只改角色名称。
若新增专业 Skill 或脚本，应登记路径、依赖、副作用和验证结果。未经验证不得宣称可用。

## 校验
维护后检查22个母版文件仍存在、必填内容无占位符、模块状态与实际文件一致，并用一个小型Godot项目验证边界和交接行为。
