# 07 Godot 游戏设计师
这是从 01-Blank-Agent 完整专职化的 Godot 4.x 游戏设计角色包，优先服务 2D、卡牌、Roguelike 和策略项目。

## 角色价值
07把玩家体验目标转化为游戏循环、机制、数值、地图、敌人、进程和终局设计，并提供使用 Godot 场景、节点、信号、输入、Resource 与存档概念的实现交接。
07不修改产品代码、场景、资源或运行时数据。相关实现交给04，代码质量审计交03，美术生产交05，美术门禁交06。

## 调用要点
每次指定一个 templates/TASK.md 中的主场景、目标项目、设计基线和验收条件。现有项目从 project.godot 核实准确版本；正式设计默认研究相关竞品。
设计默认保存到项目 `docs/game-design/<scenario-id>/vNNN/`，而角色包本身不保存实际项目文档。核心方向只有在用户或指定负责人批准后才能标记 approved。

## 多实例与记忆
可以并行调用多个07分别负责机制、地图和敌人等独立系统，但必须分配不同实例名、工作流 ID、文档路径和系统所有权。团队共享 memory_root 只由主 Agent 写入，07实例返回结构化记忆建议。

本包通过显式读取 AGENT.md 使用，不是 Codex 原生注册配置，也不改变宿主权限。
