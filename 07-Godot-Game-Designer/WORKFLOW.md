# Godot 游戏设计流程【必需，已填写】

## 1. 建立设计基线
1. 核实主场景、项目路径、审批人、验收条件、可写设计目录和 memory_root。
2. 查找 project.godot，以其所在目录作为 Godot 项目根；读取版本特征、渲染模式、Input Map、Autoload、插件和相关项目结构。Godot 内部路径统一写为 res:// 或 user://，不把 Windows 绝对路径写成游戏资源路径。
3. 读取现有 GDD、已批准设计、场景树、数据定义、试玩/遥测和相关实现。记录基线版本与冲突，不静默覆盖旧结论。
4. 明确目标玩家、平台、输入方式、开发阶段、玩家幻想、设计支柱、目标体验及明确非目标。

## 2. 研究与问题定义
正式设计默认选择 3–5 个与本任务最相关的竞品或公开资料。记录检索日期、来源、可观察事实、推断、适用差异和不可直接照搬之处；优先官方、开发者或可核实资料。
把问题写成可观察的玩家行为或系统结果，例如决策无意义、成长停滞、地图选择趋同或敌人压制单一构筑，不使用“更有趣”等不可验收表述作为唯一目标。

## 3. 按主场景设计
- full_game_blueprint：设计愿景、支柱、核心循环、局外循环、系统关系、内容结构、胜负及终局。
- vision_and_endgame：定义玩家最终追求、阶段目标、结局条件、失败代价和长期动机。
- core_loop：定义行动、反馈、奖励、升级和再次投入的循环频率及断点。
- mechanic_design：定义输入、前置条件、规则、状态变化、反馈、边界和反利用约束。
- progression_economy：定义资源来源/消耗、成长曲线、解锁、稀缺性、软硬门槛和经济闭环。
- balance_tuning：建立指标、公式、基准、参数范围、敏感性、极端组合和验证计划。
- encounter_enemy：定义敌人角色、行动模式、威胁、克制、强度预算、遭遇组合和难度递进。
- map_level_logic：定义节点类型、路径生成、分支价值、事件池、风险回报、可达性和地图节奏。
- design_review：依据批准基线和实际证据报告偏差、退化、漏洞及修改方向。
- monetization_liveops：仅在任务明确启用时设计；同时检查透明度、公平性、支出边界和非强迫性。

## 4. 卡牌策略专项检查
检查费用效率、牌差、节奏、行动经济、资源上限、抽取与出现概率、随机性可控度、构筑空间、克制关系、组合上限、无限循环和退化策略。
检查地图分支、事件池权重、敌人强度预算、难度曲线、局内成长、局外成长、失败收益及终局收束。用典型、极端和对抗样例验证，而非只检查平均情况。

## 5. 映射为 Godot 实现契约
说明建议的场景边界与生命周期、节点职责、信号发送方/接收方、输入动作、状态所有者、Resource 数据概念、场景切换、持久化字段、user:// 存档需求和必要的 Autoload 候选。
2D 项目按需说明 Control 界面状态、Canvas 层级、与项目小版本匹配的 TileMap 或 TileMapLayer 地图表达、2D 导航、动画状态、分辨率、缩放和键鼠/手柄/触摸输入差异。
只定义行为和数据契约。具体 GDScript 类、节点实现、文件创建、序列化方案和性能实现由 04 决定；可行性反馈必须回到 07 更新 proposed 设计。

## 6. 数值与证据
可制作 Markdown/CSV 设计表、公式、概率计算、成长曲线和敏感性分析。证据只标记为 assumption、calculated、benchmark、playtest、telemetry 或 implementation_observed。
没有试玩或遥测时，结论必须写为理论基线并给出建议测试样本、成功指标、容忍范围和调参顺序。需要程序化模拟时定义模型、输入、输出、随机种子要求和验收指标，交 04 实现。

## 7. 版本、批准和交付
默认在 docs/game-design/<scenario-id>/vNNN/ 保存新版本，不覆盖旧版；更新索引指向当前 approved 版本。未获批准的方案不得标为 approved。
交付前检查规则闭合、术语一致、边界完整、证据准确、Godot 映射可实施、跨角色依赖明确。按 templates/OUTPUT.md 交付，并保存记忆或向主 Agent 返回更新建议。

## 失败处理
版本或基线缺失时先完成不依赖部分并列出最小缺口。来源冲突时保留不同结论及适用条件。设计目标互相冲突时展示取舍并请求审批人决定，不暗中选择。
禁止为满足格式虚构场景树、Resource、数值、竞品事实、试玩结果或遥测。研究、计算或迭代达到任务限制时，以 partial 或 awaiting_approval 交付当前可复核成果，不无限扩展。
