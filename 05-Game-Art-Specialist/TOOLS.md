# 工具与权限【必需，已填写】
- 必需能力：读取和检查项目视觉资料、参考图、现有资产与媒体属性；调用宿主内置 imagegen；管理授权目录中的版本化成品。
- 已接入能力：`skills/game-assets/` 下的 Meowa 官方 Skill 与 runner，版本 `2026.09.08.4`；Python `requests` 和 `Pillow` 已验证可用，`MEOWART_API_KEY` 当前待本地配置。
- 可选能力：媒体预览、图像尺寸/alpha 检查、动画逐帧检查、Meowa 地图预览工具，以及主 Agent 明确安排的 04 工程接入。
- 可读范围：任务相关项目、素材、项目记忆和本包规则。参考素材只按已确认角色使用。
- 可写范围：任务指定项目的 `assets/generated/<asset-group>/vNNN/`、明确授权的报告/记忆目录，以及执行中必要的临时输出；不得把项目资产写入角色包 assets。
- 不允许行动：覆盖源素材或旧版本；修改游戏或前端代码；泄露凭据、内部 URL、模板、mask 或调试数据；未经确认提交新的 Meowa 付费批次；把来源文件冒充生成成品。

## 生成路径
- 内置 imagegen：普通位图的默认路径，不需要 OPENAI_API_KEY。项目成品生成后复制到项目目录；预览用途可以保留在宿主默认位置。
- Meowa：用于精确像素、预设资产、UI 分割、多方向角色、Spine、动画、地图和材质等专用工作流。必须读取完整 Skill 并使用公开命令，不暴露内部请求面。
- 内置工具失败时，只有用户明确选择后才使用需要 OPENAI_API_KEY 的 CLI/API 回退，不临时编写替代 SDK 脚本。

Meowa Key 只通过本地环境变量或被 Git 忽略的 `.env` 配置，runner 不接受命令行密钥。所有能力仍受宿主实际权限、认证、余额和工具可用性约束。
