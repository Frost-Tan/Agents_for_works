# 游戏美术生产流程【必需，已填写】
1. 核实项目、用途、平台、风格、HD/像素、尺寸或比例、透明度、格式、数量、视角、帧数、交付结构、参考素材授权和验收条件。读取项目现有风格、命名、锚点与导入约定以及项目记忆。
2. 建立最小完整资产契约并选择路径：普通位图生成/编辑使用内置 imagegen；需要 Meowa 专业交付结构时读取 skills/game-assets/SKILL.md 和 capability-routing.md，再读取选定能力模块。
3. 内置 imagegen 在规格明确后直接生成；本地编辑目标先实际查看，清楚列出必须保持不变的部分。多种不同资产分别生成，不用一个变体调用代替不同提示词。
4. Meowa 首次使用先按 meowart_api.md 指导本地认证并验证余额。每个新付费批次先请求确认；确认后查看实际命令帮助，以新的明确输出目录运行一个主要命令。中断任务使用原 job ID 对应的 poll 命令恢复，禁止重新提交。
5. 仅在下游能力明确接受当前输出且资产契约需要时继续编辑、去背景、方向组、动画或地图组装。动画前先稳定静态设计；每次生成式迭代只改变一个关键约束。
6. 打开并检查每个最终媒体和 Meowa 的 final_outputs.json。按资产类型检查主体、构图、风格、实际尺寸、格式、透明度、边缘、文字、像素网格、切片、锚点、方向、帧和播放效果，并在目标游戏尺寸下复核可读性。
7. 将成品非破坏性保存到 `assets/generated/<asset-group>/vNNN/final/`，预览保存到 `previews/`，生成 `asset-manifest.md`。内置 imagegen 的项目成品必须从默认生成位置复制到项目目录。
8. 按 templates/OUTPUT.md 交付。需要代码、资源导入或页面实现时，向 04 提供最终文件、命名、尺寸、状态、切片、锚点、布局和使用说明。

## 失败与停止条件
- 内置 imagegen 不可用：说明需要用户明确选择的 API/CLI 回退；不自行索取或使用 OPENAI_API_KEY。
- Meowa 未认证或余额不足：不索取密钥、不提交任务；能力等价时可建议内置 imagegen，否则说明专业交付缺口。
- Meowa 任务中断：保留 job ID 和输出目录，优先 poll；不得因超时直接发起新的付费任务。
- 结果未满足契约：保留旧版本，指出单一主要偏差再迭代；新的 Meowa 批次重新确认费用。
- 参考素材授权不明：只提取抽象方向，不生成高度复刻资产，不公开或回传参考原件。
- 专业能力不匹配：如实返回 partial/blocked，不伪造组件、无缝纹理、方向或动画属性。
