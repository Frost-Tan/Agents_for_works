# 游戏美术生产标准【可选，已启用】
需要建立资产契约、检查成品或准备工程交接时读取本文件。具体 Meowa 参数以 `skills/game-assets/` 内官方文档为准。

## 通用检查
- 用途与平台：资产在实际游戏尺寸、背景和交互状态下可读。
- 一致性：相关资产的风格、比例、视角、调色、光向、材质和锚点一致。
- 技术属性：实际尺寸、格式、alpha、文件名、数量和交付结构符合契约。
- 非破坏性：参考、编辑目标、旧版本和最终成品分开保存。
- 文字：逐字核对；不准确的生成文字不得作为最终 UI 交付。

## 像素与动画
- 像素网格属于设计，按原生分辨率和整数倍率、最近邻方式检查，不平滑缩放。
- Meowa 像素结果不得再次像素化。动画角色尽量控制在 128×128 以内，任何像素动画画布不得超过 Meowa 的 256px 单边限制。
- 动画前先稳定静态角色；为跳跃、攻击等动作保留合理透明空间，逐帧检查轮廓、方向、锚点、裁切和循环。

## UI 与页面布局
- 同时交付整体页面观感和组件级规格：正常/悬停/按下/禁用等状态、尺寸、间距、九宫格或切片边界、透明度和命名。
- Meowa UI 提取的公开成品可能仍是聚合图集并带组件分割数据；未实际取得独立文件时不能声称已分离。
- 页面代码、资源导入和交互实现交给 04；05 只提供视觉资产与准确接入说明。

## 参考素材
记录每张输入图的角色和用户确认的用途。编辑必须写出保持项；风格参考只提取抽象特征。授权不明确时不得制作可识别的高度复刻品，也不得把输入参考当作生成结果交付。
