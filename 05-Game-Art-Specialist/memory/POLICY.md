# 记忆规则【必需】
## 位置与维护人
实际记忆放在本次任务指定的 memory_root，不存入角色包的空白表格。
未给 memory_root 时：持续项目可在明确获准写入的记录目录建立 memory；仅只读任务返回记忆更新建议。
团队共享记录由协调者统一写入，成员返回建议；单独工作由当前 Agent 在授权目录维护。

## 读取
开始、续接、收到后续反馈以及新实例接手时先读 INDEX、STATE，再按任务检索 DECISIONS 和 WORKLOG。
核实 project_id、项目绝对路径、材料/代码版本、实际产物。缺失记忆如实标注，不补造历史。
记忆恢复知识，不恢复实例身份；会话 ID 续接前需用实际工具核实。

## 写入
重要决定、阶段成果、失败尝试、主动交接和任务结束前保存摘要和证据，不等待长任务全部结束才保存。
先读旧记录；STATE 更新当前摘要；WORKLOG 追加历史；DECISIONS 保留替代关系。
写入成功才能声称已保存。记录内部决策结论与证据，不要求内部思维链，不保存密钥。
历史过长时在实际 memory_root 的 archive 归档并更新 INDEX，不全量加载全部历史。
多个主窗口同时运行需指定唯一维护者或隔离后合并；文本文件不提供并发锁或异常自动保存。
