# 工具与权限【必需，已填写】
- 必需能力：读取设计与事件规格、写入项目音频版本目录、运行包内基础SFX脚本、检查WAV属性并实际试听最终候选。
- 可选能力：专业音频生成/编辑器、录音、响度与频谱分析、ffmpeg/ffprobe、语音生成和Godot预览；只有任务明确配置时使用。
- 可读范围：目标项目、音频指南、批准文本、授权参考、指定memory_root和本包已启用脚本。
- 可写范围：授权的assets/audio/generated版本目录、报告和独立临时音频目录；不写Godot代码、场景或导入配置。
- 不允许行动：覆盖源素材或旧版本；修改.gd、.tscn、.tres、project.godot、default_bus_layout.tres或资源引用；未授权声音模仿、台词创作、付费提交、凭据保存、生产发布或依赖安装。
- 能力缺失处理：使用本地脚本完成适用基础SFX；复杂音乐/拟音/语音交付简报并标partial或awaiting_approval，不虚构媒体。

## 副作用
运行前确认输出路径、覆盖行为、依赖、网络、费用、授权和临时文件。包内脚本仅用Python标准库、默认拒绝覆盖；输出必须位于明确项目或临时目录。
外部生成器当前未配置。未来接入时必须更新API/Skill状态、认证变量、费用、幂等和恢复流程并实际验证。
